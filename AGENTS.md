# AGENTS.md

## Commands

There's no local build step or lint/typecheck/test scripts in this repo.
GitHub Pages builds the site with its native Jekyll pipeline on every push
to `main`. To preview locally, install Jekyll/Bundler and run:

```bash
bundle exec jekyll serve
```

## Architecture

- Plain Jekyll site — no custom build script, no CI workflow. GitHub Pages
  builds and deploys automatically on push (Settings → Pages → "Deploy from
  a branch").
- **Posts live in `_posts/`**, named `YYYY-MM-DD-HHMM.md` (Jekyll's required
  date-prefixed filename format; no title needed for short posts). The
  `defaults` block in `_config.yml` applies `layout: post` to all of them.
- **Permalinks** are `/:year-:month-:day-:title.html` (set in `_config.yml`)
  — flat, and collision-proof even if two posts share the same HHMM on
  different days.
- `_layouts/default.html` holds the sidebar/page chrome, inline CSS, and
  per-page SEO meta (canonical, Open Graph, Twitter, RSS `{% feed_meta %}`).
  `_layouts/post.html` wraps individual posts in the `h-entry` microformat
  markup used by `index.html` and `archive.html` too.
- `index.html` lists all posts on the home page; `archive.html` lists them
  as a compact one-line-per-post feed; `about.html` is a static page.
- `media/` holds post images, referenced with plain `/media/...` paths
  (the site is served from the domain root, not a subpath, so no
  `relative_url`/baseurl handling is needed).
- `feed.xml` is generated by the `jekyll-feed` plugin (declared in
  `_config.yml`'s `plugins:` — on GitHub's safe-plugin list, no Gemfile
  needed for the native Pages build).

## Conventions

- Post HTML is user-authored Markdown, not fetched/sanitized from an
  external API — no HTML-sanitization step needed here.
- Canonical/OG/Twitter URLs are computed via Jekyll's `absolute_url` filter
  against `site.url`, which Jekyll derives from `CNAME`
  (`https://amitkathuria.com`).

## CI/Deploy

- No GitHub Actions workflow. GitHub Pages' native Jekyll build handles
  build + deploy on every push to `main`.
